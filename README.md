# Flight portfolio (Next.js)

1. `npm install`
2. `npm run dev` and open http://localhost:3000
3. Edit your content in `data.js`. Colours and fonts are CSS variables at the top of `app/globals.css`.
4. Add mp3 files to `public/music` and list them in `songs` in `data.js` (or set `songs = []` to hide the player).
5. Deploy: push to GitHub and import the repo on Vercel.
